# Memory Mods

11 hosted mods. Each entry opens its local mod page, source files and setup instructions.

- **[Cache Countdown](cache-countdown/)** by Seongje Hong - See how long your prompt cache has left before it expires, so you can time your next message before the conversation needs to be cached again.
- **[Cache Keeper](cache-keeper/)** by Nate Herk - Keep the prompt cache warm, receive warnings before a cold restart, browse local chats on one board and hand work off to a fresh conversation.
- **[Cache Timer](cache-timer/)** by Mehmet Aras - Watch a countdown to prompt-cache expiry so you can send another message before the full conversation needs to be cached again.
- **[Cold Cache Guard](cold-cache-guard/)** by Mediavee - Review your options before Claude resends a large conversation after its prompt cache expires, including when you resume an idle session.
- **[Compaction History](compaction-history/)** by Mehmet Aras - Save each compaction summary together with the files edited beforehand, so you can recover context that would otherwise disappear from the conversation.
- **[Context Relay](context-relay/)** by retrocodes12 - Hand an ongoing task to a fresh session with its working context, so you can continue without carrying the entire long conversation forward.
- **[Persistent Notes](persistent-notes/)** by Mehmet Aras - Pin standing instructions that are restored after compaction or clearing the conversation, with optional folder-specific notes that persist between sessions.
- **[Session Notes](session-notes/)** by udaaff - Keep project notes, running development servers, recent artifacts and pinned links in a side panel backed by a local Markdown file.
- **[Session Saver](session-saver/)** by Hamza Zafar - Save where you left off, give untitled conversations a name and see the saved handoff when you resume a session.
- **[Token Weather](token-weather/)** by Hamza Zafar - Watch a live forecast of your context-window usage and a countdown to prompt-cache expiry above the prompt.
- **[Tool Trim Compaction](tool-trim-compaction/)** by okamyuji - Remove older tool calls and their results during compaction while retaining conversation messages verbatim. If that saves too little space, the normal summary process takes over.
