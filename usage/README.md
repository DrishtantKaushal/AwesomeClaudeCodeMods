# Usage & costs

9 hosted mods. Each entry opens its local mod page, source files and setup instructions.

- **[Braille Usage](braille-usage/)** by kawase1295 - Model, context window and rate-limit (5h / 7d) braille meters in a band above the prompt
- **[Burn Meter](burn-meter/)** by OneWave AI - Live session cost odometer above the prompt: a burning fuse, real-world comparisons, threshold alerts
- **[Change Ledger](change-ledger/)** by Mehmet Aras - Lists the files this session edited in a pane (/changes), with line counts and who edited them, beside the git working tree
- **[Model Shortcuts](model-shortcuts/)** by Richard Kuo - Keyboard shortcuts that step the reasoning effort level and the model up and down; the footer shows what each request uses
- **[Token Weather](token-weather/)** by Hamza Zafar - A live forecast of the context window, with a prompt-cache countdown, drawn above the prompt.
- **[Turn Summary](turn-summary/)** by Mehmet Aras - Turns the line under each answer into a turn summary (tools, requests, tokens, cache hit) and shows the running tool in the spinner
- **[Usage Bars](usage-bars/)** by Hamza Zafar - Your plan's 5-hour and 7-day usage as small bars above the prompt, with the reset countdown and the session's cost.
- **[Usage Report](usage-report/)** by Schweem - Shows context fill, 5-hour and weekly quota, and session cost on the status line under the prompt, with warnings near your limits.
- **[Usage Wrapup](usage-wrapup/)** by Kevin Koch - When your plan usage gets low, tells every running agent to wrap up before the limit cuts it off.
