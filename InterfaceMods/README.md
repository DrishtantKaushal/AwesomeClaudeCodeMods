# Interface Mods

12 hosted mods. Each entry opens its local mod page, source files and setup instructions.

- **[Animated Spinner](animated-spinner/)** by Sai Rudra - Clawd acts out the spinner's word above it while Claude works: cooking for Sautéing, dancing for Vibing, pacing for Pondering, 11 acts across all 179 words.
- **[Diagram Viewer](diagram-viewer/)** by Mehmet Aras - Draws the mermaid diagrams of each answer as images in a pane (/show-me); needs mmdc and a kitty-graphics terminal such as Ghostty
- **[Image Peek](image-peek/)** by Mehmet Aras - Shows the images you paste: thumbnails above the prompt, and larger pictures under each sent message in the chat; needs a kitty-graphics terminal such as Ghostty
- **[Image Viewer](image-viewer/)** by Jarrod Watts - See the images you paste into Claude Code: thumbnails above the prompt instead of bare [Image #1] tags
- **[Inner Monologue](inner-monologue/)** by OneWave AI - A pane of Claude's dry inner thoughts about your session, typed out live
- **[Launch Codes](launch-codes/)** by OneWave AI - Dangerous Bash commands need launch codes: red alert pane, siren, a code to arm and a LAUNCH to fire
- **[Mermaid Diagrams](mermaid-diagrams/)** by Gal Elmalah - Mermaid diagrams in Claude Code: every ```mermaid block Claude writes is drawn as box art, in colour, right where the fence was in the transcript. Needs function hooks (early access) and an interactive terminal.
- **[Question Picker](question-picker/)** by Takashi Ogishima - Ask the user a question in a dedicated pane: show every option on one screen with a summary, single or multi-select, no 4-option limit.
- **[Session Notes](session-notes/)** by udaaff - Project notes in .claude/notes.md: live dev servers, recent artifacts and pinned links, in a side panel and with /notes.
- **[Shell Highlight](shell-highlight/)** by Turbo-Thorschten - Draws Bash and PowerShell tool calls with syntax-highlighted commands
- **[Turn Timeline](turn-timeline/)** by Mehmet Aras - Draws the current turn as a timeline in a pane (/timeline): model requests and tool calls per loop, where the time went, and the slowest steps
- **[Video Breaks](video-breaks/)** by Hamza Zafar - YouTube Shorts in a terminal pane: plays while Claude works, pauses when Claude is done.
