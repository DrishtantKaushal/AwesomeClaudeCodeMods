# Interface Mods

8 hosted mods. Each entry opens its local mod page, source files and setup instructions.

- **[Animated Spinner](animated-spinner/)** by Sai Rudra - Replace the standard waiting animation with a character that acts out the spinner’s status, such as cooking, dancing or thinking while Claude works.
- **[Diagram Viewer](diagram-viewer/)** by Mehmet Aras - View Mermaid diagrams from Claude’s answers as rendered images in a side pane. It requires the Mermaid command-line renderer and a terminal with Kitty graphics support.
- **[Image Peek](image-peek/)** by Mehmet Aras - Preview pasted images above the prompt and beneath sent messages, then open larger inline views. Image display requires a terminal that supports Kitty graphics.
- **[Image Viewer](image-viewer/)** by Jarrod Watts - See thumbnails of images you paste above the prompt, so you can identify each attachment without relying on numbered image tags.
- **[Japanese Session Names](japanese-session-names/)** by tomatoaiu - Generate a Japanese session title from the conversation by running /rename without arguments, making saved sessions easier to recognize.
- **[Mermaid Diagrams](mermaid-diagrams/)** by Gal Elmalah - Read Mermaid diagrams directly in the conversation as colored text-based drawings, without opening a separate diagram viewer.
- **[Read Aloud](read-aloud/)** by repository owner gnehiur - Listen to Claude’s replies through Volcengine’s Doubao speech service, with controls to pause, resume, restart or change the playback speed.
- **[Shell Highlight](shell-highlight/)** by Turbo-Thorschten - Read Bash and PowerShell tool calls with syntax highlighting, making the commands easier to inspect before following their results.
