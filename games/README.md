# Games & entertainment

8 hosted mods. Each entry opens its local mod page, source files and setup instructions.

- **[Boss Fight](boss-fight/)** by OneWave AI - Failing tests spawn a pixel boss; every run that fixes tests lands a hit, zero failures is a KO with loot
- **[Code Pet](code-pet/)** by OneWave AI - A pixel pet that lives in a pane and reacts to what Claude does: eats on tool calls, gets sick on failures, panics on rm -rf, sleeps when idle, evolves as you ship
- **[Dino Game](dino-game/)** by Giovanni Borgogno - The T-rex from the browser's offline page, above the Claude Code prompt: jump cacti and duck birds while Claude works. Needs function hooks (early access) and an interactive terminal.
- **[Dino Runner](dino-runner/)** by manfye - The Chrome offline dinosaur, above the Claude Code prompt. Jump the cacti and duck the pterodactyls while Claude works. Needs function hooks (early access) and an interactive terminal.
- **[Snake Game](snake-game/)** by Hamza Zafar - Snake in a pane while Claude works, paused when it's done. Opt-in, so nothing opens until /snake.
- **[Spell Bar](spell-bar/)** by powerofjinbo - An animated effort bar for Claude Code: Clawd casts Avada Kedavra at six ranks, one per effort level from low to ultracode, with Voldemort looming behind.
- **[Sportscaster](sportscaster/)** by OneWave AI - Live TV play-by-play of your Claude Code session, spoken aloud with crowd effects
- **[Terminal Arcade](terminal-arcade/)** by Seza Akgün - Games above the Claude Code prompt (snake, Tetris, 2048, Minesweeper, Flappy, Pong, typing test, Space Invaders, Doom) plus a pet that grows as Claude tests, commits and edits. Clones of the genre, not affiliated with or endorsed by Tetris Holding, Taito, Atari or id Software. Needs function hooks (early access) and an interactive terminal.
