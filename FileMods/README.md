# File Mods

2 hosted mods. Each entry opens its local mod page, source files and setup instructions.

- **[File Activity Map](file-activity-map/)** by y-hirakaw - See which files Claude has listed, read, edited, created or deleted through a project tree and activity map beside the conversation.
- **[Markdown Preview](markdown-preview/)** by Hamza Zafar - Read Markdown files in a rendered pane beside the conversation and compare their before-and-after versions while Claude edits them.
