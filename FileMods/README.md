# File Mods

4 hosted mods. Each entry opens its local mod page, source files and setup instructions.

- **[File Activity Map](file-activity-map/)** by y-hirakaw - See which files Claude has listed, read, partially read, edited, created or deleted, as a tree and an activity map in a pane.
- **[Markdown Preview](markdown-preview/)** by Hamza Zafar - Shows the Markdown files Claude edits, rendered like GitHub, in a pane next to the chat. Before and after side by side. /md opens it.
- **[Private Recording](private-recording/)** by Nate Herk - /rec before you record: masks keys, personal details, and business figures on screen and keeps private files closed (/rec strict, /rec off, /rec config)
- **[Search Meter](search-meter/)** by Mehmet Aras - Counts the model's searches and colors each one: green found first try, yellow found after misses, red found nothing
