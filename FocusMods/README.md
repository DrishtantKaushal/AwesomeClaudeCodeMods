# Focus Mods

3 hosted mods. Each entry opens its local mod page, source files and setup instructions.

- **[Attention Summary](attention-summary/)** by Hamza Zafar - See upcoming meetings, pull requests, Linear issues and Slack messages that need your attention in one summary above the prompt.
- **[Breathing Exercises](breathing-exercises/)** by Anthony - Follow guided breathing exercises while Claude works, with animated pacing for box breathing, the physiological sigh and other supported breathing patterns.
- **[Inbox Alerts](inbox-alerts/)** by OneWave AI - See Gmail and Slack notifications inside Claude Code, with toast alerts, an unread count and a dedicated pane for checking incoming messages.
