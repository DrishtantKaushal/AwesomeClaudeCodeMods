# Usage & costs

9 hosted mods. Each entry opens its local mod page, source files and setup instructions.

- **[burn-meter](OneWave-AI--claude-code-mods--burn-meter/)** by OneWave AI - Live session cost odometer above the prompt: a burning fuse, real-world comparisons, threshold alerts
- **[change-ledger](arasovic--claude-code-mods--change-ledger/)** by Mehmet Aras - Lists the files this session edited in a pane (/changes), with line counts and who edited them, beside the git working tree
- **[model-effort-shortcuts](richkuo--claude-code-model-effort-shortcuts/)** by Richard Kuo - Keyboard shortcuts that step the reasoning effort level and the model up and down; the footer shows what each request uses
- **[token-weather](hamzafer--claude-code-mods--mods--token-weather/)** by Hamza Zafar - A live forecast of the context window, with a prompt-cache countdown, drawn above the prompt.
- **[turn-footer](arasovic--claude-code-mods--turn-footer/)** by Mehmet Aras - Turns the line under each answer into a turn summary (tools, requests, tokens, cache hit) and shows the running tool in the spinner
- **[usage-meter](hamzafer--claude-code-mods--mods--usage-meter/)** by Hamza Zafar - Your plan's 5-hour and 7-day usage as small bars above the prompt, with the reset countdown and the session's cost.
- **[usage-meter](kawase1295--usage-meter/)** by kawase1295 - Model, context window and rate-limit (5h / 7d) braille meters in a band above the prompt
- **[usage-report](Schweem--usage-report/)** by Schweem - Shows context fill, 5-hour and weekly quota, and session cost on the status line under the prompt, with warnings near your limits.
- **[usage-wrapup](DaKev--usage-wrapup/)** by Kevin Koch - When your plan usage gets low, tells every running agent to wrap up before the limit cuts it off.
