# Files & navigation

4 hosted mods. Each entry opens its local mod page, source files and setup instructions.

- **[md-preview](hamzafer--claude-code-mods--mods--md-preview/)** by Hamza Zafar - Shows the Markdown files Claude edits, rendered like GitHub, in a pane next to the chat. Before and after side by side. /md opens it.
- **[recording-mode](nateherkai--claude-code-mods--recording-mode/)** by Nate Herk - /rec before you record: masks keys, personal details, and business figures on screen and keeps private files closed (/rec strict, /rec off, /rec config)
- **[search-meter](arasovic--claude-code-mods--search-meter/)** by Mehmet Aras - Counts the model's searches and colors each one: green found first try, yellow found after misses, red found nothing
- **[touch-map](y-hirakaw--claude-code-mods--touch-map/)** by y-hirakaw - See which files Claude has listed, read, partially read, edited, created or deleted, as a tree and an activity map in a pane.
