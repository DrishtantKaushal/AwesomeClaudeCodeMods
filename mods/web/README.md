# Browser & web

2 hosted mods. Each entry opens its local mod page, source files and setup instructions.

- **[browser-lanes](hamzafer--claude-code-mods--mods--browser-lanes/)** by Hamza Zafar - Shows if this session has a Playwright browser and who holds it. /browser clean closes leftover browsers. A subagent that wants the browser waits until the one using it is done.
- **[html-preview](JAICHANGPARK--html-preview/)** by JAICHANGPARK - Shows HTML files Claude writes (or /preview <file>) like a browser: terminal-browser when installed, else a built-in Chrome-rendered pane
