# Git Mods

3 hosted mods. Each entry opens its local mod page, source files and setup instructions.

- **[CI Watch](ci-watch/)** by Mehmet Aras - Watches GitHub Actions in a band above the prompt after Claude pushes, opens a PR or pushes a tag: a progress bar per run, then pass or fail; optionally flags failed scheduled workflows at start
- **[Merge Gate](merge-gate/)** by Hamza Zafar - Holds `gh pr merge` until CI passes and one Codex review (OpenAI's luna model) has run. A PR line above the prompt, and /gate shows the PR's status.
- **[PR Tracker](pr-tracker/)** by Seza Akgün - Watch GitHub PRs from a Claude Code session: merge state, review and required checks above the prompt, with alerts when they change
